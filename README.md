# Revisio

Spaced-repetition learning platform — Next.js + TypeScript + Tailwind + Postgres (Supabase).

- Daily SRS reviews (cloze, flashcards, MCQ) with a tolerant grading engine
- Cram mode, exam simulator, learn-content library
- XP, streaks, leagues, achievements (opt-out honored)
- Teacher classes + analytics, developer admin (approvals, flags, algorithms)
- Postgres schema managed via drizzle; runs on Supabase
